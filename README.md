# Cambridge Exams Presentation

This project is a code-based presentation template designed for **Cambridge Exams**, built entirely with HTML5 and CSS3.  
Modern, professional slides can be created without relying on software like PowerPoint or Keynote.  
By using standard web technologies, you can easily build, customize, and version-control your slideshows just like any other codebase.

## 🛠️ Getting Started

### 1. View the Slides Locally
Clone the repository and open the HTML file in any modern web browser:
```bash
git clone https://github.com/ZCodingSpace/Cambridge-Exams-Presentation-102026.git
cd Cambridge-Exams-Presentation-102026
```
Then, double-click `Cambridge Exams Presentation.html` to open it in Chrome, Firefox, Edge, or Safari.

### 2. Customizing the Content
Open `Cambridge Exams Presentation.html` in your favorite code editor (like VS Code) to edit or add new slides. You can structure your elements inside slide wrappers and control their aesthetic feel via `Cambridge Exams Presentation.CSS`.

### 3. Exporting to PDF
To update or generate a new PDF version of your presentation:
1. Open the `.html` file in your browser.
2. Press `Ctrl + P` (or `Cmd + P` on Mac) to open the print dialog.
3. Set the destination to **Save as PDF**.
4. Enable **Background graphics** in the print settings to ensure colors and images render correctly.

## 📝 Note on Code-Based Presentations

Traditional presentation apps limit you to drag-and-drop interfaces that are difficult to track in git. **With this repository, your slides are treated as pure source code.** This allows you to:
* Use standard Git workflows to track text and layout changes over time.
* Maintain pixel-perfect design alignment using absolute CSS positioning, flexbox, or grid layouts.
* Avoid corrupt binary files and bloated presentation sizes.
